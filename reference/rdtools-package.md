# rdtools: Efficient Manipulation of 'Rd' Files and Help Topics

Provides fast, cached lookup of help topics and aliases across
installed, source, and in-development packages, plus efficient retrieval
of parsed 'Rd' ('R' documentation) objects. Per-package indexes are
built once and cached, making repeated lookups cheap enough to call in a
tight loop.
